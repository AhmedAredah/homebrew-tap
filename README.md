# Homebrew tap

Homebrew formulae by Ahmed Aredah.

```bash
brew install AhmedAredah/tap/qavf
```

| Formula | Description |
|---|---|
| [`qavf`](Formula/qavf.rb) | [QAVF](https://github.com/AhmedAredah/qavf): configurable data QA/QC for files, dataframes and database queries |

QAVF installs into a private virtual environment with its dependencies as their
official wheels, including the `stats` extra. For Python projects, prefer
`pip install qavf` or `uv tool install qavf`.
